# Lumina Frontend - LLM Module (Infomaniak AI)

## Quick Start

### Installation

```console
cd ./client
npm install
```

Edit both 'auth' and 'api' in vite.config.js : http://localhost:8000 with your backend ip.
By default client is accessible on localhost:8080 and backend is accessible on localhost:8000

### Execution

```console
npm run dev
```

### Frontend (`client/.env`)
- `VITE_API_URL`: Backend API endpoint (default: `http://localhost:8000`).
